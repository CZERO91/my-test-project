# JSON 表单渲染器 - 产品需求文档

## 1. 产品概述

一个基于 React 的动态 JSON 表单渲染器，支持通过导入 JSON 配置文件或直接输入 JSON 来动态生成表单界面。用户可以预览、填写并提交表单数据，同时支持将表单配置保存到 Supabase 进行持久化存储。

- **目标用户**：需要快速构建动态表单的开发者和业务人员
- **核心价值**：通过 JSON 配置快速生成表单，无需编写代码，提高表单开发效率

## 2. 核心功能

### 2.1 功能模块

1. **渲染器页面**：核心表单渲染组件，根据 JSON 配置动态生成表单
2. **导入页面**：支持 JSON 文件导入和手动输入，调用渲染器预览表单

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 渲染器页面 | 表单渲染器 | 根据 JSON 配置动态渲染各类表单控件，支持数据绑定和验证 |
| 渲染器页面 | 表单操作栏 | 提交、重置、获取表单数据等操作按钮 |
| 导入页面 | JSON 输入区 | 支持拖拽上传 JSON 文件或手动输入 JSON 文本 |
| 导入页面 | 预览区 | 实时预览渲染后的表单效果 |
| 导入页面 | 配置管理 | 保存配置到 Supabase、加载历史配置 |

### 2.3 支持的表单控件类型

| 控件类型 | 说明 |
|---------|------|
| input | 文本输入框 |
| date | 日期选择器 |
| select | 下拉选择框 |
| radio | 单选框 |
| checkbox | 复选框 |
| switch | 开关 |
| rate | 评分 |
| date-range | 日期范围选择器 |
| time-range | 时间范围选择器 |
| color | 颜色选择器 |
| slider | 滑块 |
| html-text | HTML 文本 |
| static-text | 静态文本 |
| button | 按钮 |

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰色系 (#1e293b) 配合亮蓝色强调色 (#3b82f6)
- **辅助色**：浅灰色背景 (#f8fafc)，白色卡片 (#ffffff)
- **按钮风格**：圆角矩形，带有微妙的阴影和悬停动效
- **字体**：使用 Inter 作为主字体，代码区域使用 JetBrains Mono
- **布局风格**：左右分栏布局，左侧为 JSON 输入区，右侧为表单预览区

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 导入页面 | JSON 输入区 | 代码编辑器风格，支持语法高亮，拖拽上传区域 |
| 导入页面 | 预览区 | 表单卡片，带有标题栏和操作按钮 |
| 渲染器页面 | 表单区域 | 表单项按配置排列，带有标签和验证提示 |

### 4.3 响应式设计

- 桌面端优先设计，采用左右分栏布局
- 移动端自适应为上下堆叠布局
- 表单控件宽度自适应容器

## 5. 技术约束

- 使用 Vite 作为构建工具
- 使用 TypeScript 进行类型安全开发
- 使用 React 18 进行 UI 开发
- 使用 Supabase 进行数据持久化
- 表单渲染器尽量保持单文件实现
